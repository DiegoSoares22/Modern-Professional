Professional landing page developed for a real client in the high-end planned furniture segment. This project was built as part of my TypeScript learning journey, applying the language in a practical, 
real-world delivery context with AI-assisted development tools.

Live: modern-professional--dsoliveir00.replit.app

About the Project
The client needed a modern, conversion-focused landing page that communicated the brand's premium positioning. I was responsible for the product conception, information architecture, navigation flow, and UX decisions, 
using AI-assisted tooling on Replit to accelerate delivery while focusing on structure and user experience.
The project gave me hands-on exposure to TypeScript in a real delivery scenario, including type configuration, project structure, and working with a component-based frontend architecture.

Technologies

TypeScript (95% of the codebase)
CSS3
HTML5
Replit (development and hosting environment)
pnpm (package manager)


What I practiced with this project

TypeScript project setup with tsconfig.json and tsconfig.base.json
Organizing a frontend project with lib and scripts separation
Working with pnpm workspaces
Delivering a production-ready application for a real client
Applying UX decisions focused on conversion and brand identity


Key Features

Premium visual identity with dark background and gold typography
Signed projects gallery with real client work
Brand differentiators section
Direct WhatsApp conversion button for lead capture
Responsive layout optimized for mobile and desktop


Learning Context
This project is part of my continuous learning path in Frontend development. As a Backend Developer transitioning toward a broader stack, I used this real client delivery as an opportunity to practice TypeScript 
outside of academic exercises, observing how it structures a production codebase and how AI tooling fits into a real development workflow.
